How to Use This Simulator

This section explains exactly how to run experiments on the virtual memory simulator and what to observe for your viva / project demo.

Step 1: Configure Inputs

• Set Number of Frames (size of physical memory).
• Enter a Reference String of page numbers (space or comma separated).
• Choose a Page Replacement Algorithm (FIFO, LRU, LFU, Second-Chance, Optimal).

Step 2: Run & Observe

• Use Run All for full simulation, or Step to go page by page.
• Watch the Frame Table, Hit/Fault Timeline and Stats (faults, hits, hit ratio, fault rate).
• Enable Tutor Mode to get explanation for each hit / fault.

Step 3: Analyze Performance

• Use Compare All Algorithms to see which one performs best.
• Use Faults vs Frames Explorer to study how increasing frames affects page faults (and Belady’s anomaly in FIFO).
• Use Download Report for final summary you can attach in your project file.

Preset Scenarios

Quickly load common patterns and observe how different algorithms respond.

  • Textbook Example: Standard sequence to test basic behavior of all algorithms.
  • High Locality: Favors algorithms like LRU/LFU which exploit recent/frequent usage.
  • Random Workload: Shows average behavior on noisy, unpredictable access patterns.
  • Belady's Anomaly Case: Loads a string designed for FIFO to demonstrate increased faults with more frames.
